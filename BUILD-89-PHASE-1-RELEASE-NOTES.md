# Build 89 — Professional Polish · Phase 1

## Purpose

Make the Home workspace feel more polished and immediately useful without changing the underlying signage operations.

## New experience

- The hero now shows live totals for Players, Schedules, Images, and screens marked Deployed.
- A time-aware greeting changes for morning, afternoon, evening, and Quiet Hours.
- Store Status now communicates in a single natural-language operational message.
- Health, compliance, deployment, and hero counters animate smoothly when values change.
- Motion is disabled automatically for visitors using reduced-motion accessibility settings.

## Unchanged behavior

- Apps Script endpoint and heartbeat storage
- Player `index.html`
- Scheduling and image selection
- Rollout stage data
- Quiet Hours and weekday expectations
- Recovery snapshot logic
